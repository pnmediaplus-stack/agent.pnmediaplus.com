# KO-10 — Experiment & Learning Capture v1.0
## Lifecycle
Evidence → Decision → Campaign → Result → Interpretation → Learning Status → Controlled Knowledge Update.

A result is not automatically a learning; a learning is not automatically reusable truth.

## Interpretation Context
Every result must be read against hypothesis, audience, creative, channel, budget, time window and material execution conditions.

## Learning Status
`OBSERVATION` → `PRELIMINARY_LEARNING` → `REPEATABLE_LEARNING` → `VALIDATED_LEARNING`.

## Output
```yaml
learning_record:
  hypothesis:
  campaign_context:
  result_summary:
  evidence: []
  confounders: []
  interpretation:
  learning_status:
  confidence_level:
  reusable_scope:
  what_not_to_generalize: []
  update_targets: []
  next_experiment:
```

## Gate 05
A single campaign result normally cannot update canonical market, ICP or pain truth. Promotion requires interpretation and appropriate repeatability/evidence.
