# PURPOSE

Defines the operating charter of PN OS Production Governance OS.

---

# CHARTER

PN OS Production Governance OS exists to ensure:

- no authority drift
- no duplicate canonical truth
- no unsafe automation
- no role creep
- no undocumented release
- no runtime bypass
- no governance mutation without review

---

# GOVERNANCE OS GUARANTEES

The system must preserve:

1. Constitutional authority
2. Canonical artifact resolution
3. Registry-based runtime loading
4. Layer isolation
5. Capability boundaries
6. Protocol consistency
7. Release auditability
8. Operational rollback
9. Human/Gatekeeper review
10. n8n execution-only boundary

---

# NON-NEGOTIABLES

- Registry is authority
- Gatekeeper is review authority
- Governance Relay is apply gate
- Architect designs and patches only
- QA reviews readiness only
- n8n executes only
- Human approves operational adoption
- Immutable law cannot be weakened

---

# PRODUCTION PRINCIPLE

A governance system is not safe because workflows run.

It is safe only when authority, evidence, replay, review, and rollback are preserved.
