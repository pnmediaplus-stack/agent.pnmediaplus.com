# PN MEDIA PLUS — DISTRIBUTION INTELLIGENCE LAYER v1.0
## Governed Modular AI OS Extension

==================================================
0. PURPOSE
==================================================

Distribution Intelligence Layer là lớp tối ưu phân phối nội dung.

Mục tiêu:
- giúp hệ thống không chỉ tạo content hay
- mà còn biết content nào nên đăng ở đâu, lúc nào, theo format nào
- tối ưu khả năng:
  - reach
  - retention
  - save
  - share
  - comment
  - soft lead
  - conversion routing

Nếu Performance Memory là nơi hệ thống “nhớ”,
thì Distribution Intelligence là nơi hệ thống “quyết định cách phát tán”.

==================================================
1. CORE PRINCIPLE
==================================================

Content tốt chưa chắc phân phối tốt.

Một bài có thể:
- caption hay
- visual tốt
- QA pass

nhưng vẫn fail nếu:
- sai platform
- sai format
- sai timing
- sai hook packaging
- sai audience segment
- sai CTA route

Distribution Intelligence tồn tại để nối:

```yaml

+

+
audience_response
+

````

==================================================
4. PLATFORM STRATEGY MAP
========================

## Facebook

Phù hợp với:

* relatable insight
* operator confession
* checklist/framework
* discussion post
* carousel
* image + caption dài vừa phải

Tối ưu:

* comment
* save
* share
* trust

Không nên:

* quá cinematic nhưng thiếu insight
* caption quá LinkedIn
* video quá abstract
* CTA bán hàng quá sớm

---

## TikTok / Reels / Shorts

Phù hợp với:

* first 2s hook
* visual immediacy
* transformation
* before/after
* tutorial nhanh
* pattern interrupt

Tối ưu:

* retention
* replay
* share
* profile click

Không nên:

* mở đầu chậm
* text quá nhiều
* context dài
* visual thiếu motion tension

---

## LinkedIn

Phù hợp với:

* operator insight
* business framework
* case study
* authority breakdown
* system thinking

Tối ưu:

* trust
* authority
* lead quality

Không nên:

* meme quá mạnh
* emoji quá nhiều
* clickbait rẻ
* visual quá giải trí

---

## YouTube Shorts

Phù hợp với:

* clear promise
* structured sequence
* repeatable series
* tutorial / breakdown

Tối ưu:

* retention
* subscriber intent
* series habit

Không nên:

* message quá mơ hồ
* không có payoff
* thiếu series identity

```yaml

    - prompt pack

  prioritize:
    - relatable confession
    - opinion question
    - pain reflection
    - identity prompt

if_goal_is_trust:
  prioritize:
    - case study
    - authority breakdown
    - calm operator insight
    - educational post

if_goal_is_soft_lead:
  prioritize:
    - problem-solution post
    - workflow reveal
    - useful template
    - CTA to comment/DM
```

6. HOOK DISTRIBUTION SYSTEM
===========================

Hook không chỉ để viết hay.

Hook phải phù hợp distribution objective.

## Hook Types

```yaml
hook_types:
  pain_recognition:
    best_for:
      - Facebook
      - save
      - comment

  utility_promise:
    best_for:
      - TikTok
      - Shorts
      - save

  contrarian_truth:
    best_for:
      - Facebook
      - LinkedIn
      - share

  visual_curiosity:
    best_for:
      - Reels
      - Shorts
      - image posts

  identity_trigger:
    best_for:
      - Facebook
      - community posts

  mistake_alert:
    best_for:
      - tutorial
      - educational content
```

## Hook Selection Rule

```yaml
hook_should_match:
  - platform
  - content_goal
  - audience_awareness_stage
  - visual_format
  - CTA route
```

10. CTA ROUTING SYSTEM
======================

CTA phải phù hợp funnel stage.

```yaml
cta_by_stage:
  awareness:
    - comment pain
    - save for later
    - share with someone

  consideration:
    - ask for checklist
    - comment keyword
    - DM for workflow

  conversion:
    - book demo
    - request audit
    - get template
    - join waitlist

  community:
    - share your case
    - vote on next topic
    - submit example
```

Không dùng conversion CTA quá sớm nếu content là awareness.

==================================================
17. FAILURE MODES
=================

## Content good but no reach

Likely causes:

* wrong format
* weak thumbnail
* poor first frame
* wrong timing
* platform mismatch

Route:

* Agent 3
* Distribution Intelligence
* Performance Memory

---

## High views but no comments

Likely causes:

* CTA weak
* content too passive
* no identity trigger

Route:

* Agent 2
* Agent 1

---

## High saves but no leads

Likely causes:

* CTA too soft
* no conversion bridge
* no follow-up sequence

Route:

* Conversion Layer future build

---

## Good caption, weak visual

Route:

* Agent 3

---

## Good visual, weak retention

Route:

* Agent 5 / Agent 6 if video
* Agent 3 if image-first
